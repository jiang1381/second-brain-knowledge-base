# RAG 原理

RAG（Retrieval-Augmented Generation，检索增强生成）先从知识库检索相关资料，再让大模型基于资料生成答案。

## 为什么需要 RAG
- 大模型有幻觉，会一本正经地编造
- 模型知识有截止日期
- 企业私有文档不在训练数据里

## 完整链路
1. 文档加载与分块（chunking），块之间保留 overlap
2. embedding 把文本转成向量，存入向量库
3. 用户提问也转成向量，用余弦相似度召回 top-k
4. 重排（rerank）后拼进 prompt
5. 模型基于资料回答，并标注引用

## 减少幻觉的手段
要求模型只根据资料回答、资料不足就说不知道、给出引用、做检索评测。
